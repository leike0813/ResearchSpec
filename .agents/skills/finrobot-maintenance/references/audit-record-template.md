# FinRobot Audit Record Template

每个锚点目录包含：

- `01-analysis.md`：上游身份、库存、extension 映射与决策。
- `02-ingestion.md`：六个 raw Skill 清单、全部 tools 清单与 SHA-256。
- `03-conversion.md`：extension capability packages、profiles、required brief fields 与验证结果。
- `04-review.md`：registry/domain 复核、package hash、机器工件与人工确认项。
- `05-semantic-review.md`：**Agent 必填**，逐项 preserved / adapted / removed / gap 判定与证据。
- `artifacts/extension-review.json`：extension package 机器审阅 slice。
- `manifest.json`：机器可验证锚点状态。
