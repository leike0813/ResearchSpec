> 范围声明：本文件结论只依据 `/benchmark/` 目录下的合成材料（来源 ID 均为 `SYN-*`）。
> `README.md` 明确这些是 dogfooding 离线测试材料，不对应真实文献、DOI、作者或外部网页。
> 未经联网核实；不补造参与者信息、效应量、引用或伦理审批。

## 按焦点的可核对结论

### 1. 学生写作过程

- 可核对：在一门一年级写作课的 6 周观察里，使用结构化 AI 提示的学生产出了更多大纲修订版本（SYN-CLASSROOM-01）。
- 可核对：同一来源记录期末 rubric 分数"varied widely"——不是整体上升，也不是整体下降。
- 未知：修订次数→写作质量的对应关系；修订的内容性质量；学生自发使用与按提示使用的差异。
- 来源已标明的边界：无对照组、无写作提升的验证量度、提示由教师提供。

### 2. 反馈质量

- 可核对：5 位教师自评，使用 GenAI 后形成性反馈更快（SYN-INTERVIEW-02）。
- 可核对：同一来源记录教师需要额外时间核查学生带来的未支持主张。
- 未知：反馈准确性、可信度的客观度量；"更快"是否伴随"更准确/更不准确"。

### 3. 教师工作量

- 可核对：教师自述出现两个反向时间项——形成性反馈时间下降，核查未支持主张的时间上升（SYN-INTERVIEW-02）。
- 未知：净时间变化；不同写作任务类型或课程容量之间是否一致。
- 来源已标明的边界：自报工作负荷；小样本方便抽样；无时间日志。

### 4. 学术诚信与制度

- 可核对：84 位自愿回应学生中，部分对"是否被允许使用 AI 辅助"以及"署名/归属"感到不确定（SYN-SURVEY-03）。
- 可核对：一所合成大学要求课程级 disclosure；可接受辅助的边界交由任课教师决定（SYN-POLICY-04）。
- 未知：政策实际落地质量；学生不确定感是否对应实际违规或申诉记录；跨机构对比。

## 观察 / 解释 / 未知的分层

- **直接观察**（每条都可逐字指回 SYN-* 字段）：
  见上四节"可核对"项。
- **受约束的解释**：四条观察拼起来，可以表述为"GenAI 同时触及多个环节——
  增量过程行为（修订次数）、反馈节奏、教师时间分配、学生对规则认知"。
  这是描述性综合，不是因果推断；不能外推到课堂之外。
- **未知**（当前 package 不支撑任何具体答案）：
  写作质量是否提升；教学效果是否变化；工作量净效果；跨机构可推广性；长期效应；
  政策落地的真实差异；学生不确定感与违规率的关系。

## 与 `goal.md` 边界对齐

`goal.md` 已声明"避免把短期课堂观察表述为普遍因果结论"。本材料支持的最低结论范围如下：

- 单门课 6 周 → 不能外推到高校写作教学整体；
- 单一机构 5 位教师 → 不能外推到教师群体；
- 84 位自愿受试 → 不能外推到学生群体；
- 一所机构的政策摘录 → 不能外推到制度层面。

任何把上述观察升级为"普遍效应"的表述都超出本 package。

## 不在范围内的事项（按 `goal.md` 约束）

- 真实参与者人口学；
- 效应量、置信区间或显著性检验；
- 伦理审批状态；
- 真实引用或 DOI；
- 对未在 SYN-* 材料中出现的人口、机构、政策的描述。

## 当前材料能直接支撑的后续产物

1. 把四点观察合并成一段简明综述，逐条标 SYN-* 出处与 scope —— 这是 package 能直接支撑的最高产物。
2. 若要支撑"普遍化结论"，需要扩展为多课程、含对照组的纵向研究；规模、参数、伦理路径均超出本 package。
3. 若要做政策评估，需要把"政策文本摘录"扩展为"政策落地审计"——本 package 仅有前者。
