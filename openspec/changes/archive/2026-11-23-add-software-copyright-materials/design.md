# Design

## Context

The domain and extension registries already support hidden Procedures, package integrity and explicit workspace selection. Discovery currently loads all extension packages strictly, coupling unrelated work to optional package files.

## Goals / Non-Goals

One mixed Procedure covers local R11 general deposit materials, manual instructions and a host-native browser handoff. Its standalone outputs are ordinary files. The existing CLI and schema versions remain the public interface.

## Decisions

- Pin the upstream Git tree and retain a file-level review. Generate the vendor and extension projections from the same authored workflow and admitted resources. Assign R11 to `intellectual-property-materials`.
- Assign patent disclosure, application, docket, and research-to-patent and their exclusive capabilities to the same domain. Reference their existing maintained package and profile files without duplicating bytes. Keep common patent search and the paper's patent intelligence and evidence merger in the base runtime.
- Apply domain selection to discovery eligibility and profile access. Existing projects can install the domain to adopt the maintained profile projections and resume with the same frozen run, role contracts, and selectors.
- Treat the applicant's case directory as the material boundary. Use a reviewed ordered source list and package-local tooling to render and check documents. Store field facts and paths in the case, alongside the proof of independent review. Keep filing records separate from the verified document index.
- Separate local acceptance from browser permission. Use current official page evidence and the host's browser tools. Keep authentication and binding acts with the applicant.
- Reuse catalog ranking and existing eligibility. Separate strict validation from runtime recovery so one invalid package cannot take down manuscript work. Preserve strict validation for installation and maintenance.

## Risks / Trade-offs

- PDF rendering and support for updating Word fields depend on host tools. Accept user exports with equivalent verification.
- The platform may change live fields and state. Compare the live origin, applicant, case, fields and upload confirmations, and prefer manual handoff when the evidence is incomplete.
- Catalog expansion can invalidate a hybrid cache. Existing offline fallback keeps discovery usable until explicit preparation.
