# Proposal

## Why

Users who register research software need a repeatable way to produce Chinese R11 materials and hand them to the filing platform. The feature belongs behind optional domain selection so a manuscript task can continue independently.

## What Changes

- Admit one reviewed software-copyright vendor package and expose one hidden Procedure through the existing Domain lifecycle.
- Add the Intellectual property materials tool domain for R11 and the patent disclosure, application, docket, and research-to-patent workflows.
- Keep patent intelligence, shared patent search, and patent-informed paper writing available by default.
- Produce and verify local materials before offering manual filing guidance or user-authorized browser assistance.
- Keep failed optional packages from interrupting core Procedure discovery and graph execution.

## Capabilities

### New Capabilities

- `software-copyright-materials` covers producing and filing Chinese R11 materials.

### Modified Capabilities

- `procedure-routing` specifies runtime behavior when an individual optional extension is damaged.
- `domain-taxonomy` includes the sixth tool domain.
- `domain-skill-plugin-registry` includes the sixth tool domain in the stable catalog.
- `patent-workflow-profiles` specifies installation and resumption for the optional patent profiles.

## Impact

Adds a maintainer-only vendor pin, reviewed materials, release checks, and one tool-domain installation. Patent profiles and packages retain their existing IDs, versions, and artifact contracts. Core manuscript profiles and workspace schemas retain their current contracts.
