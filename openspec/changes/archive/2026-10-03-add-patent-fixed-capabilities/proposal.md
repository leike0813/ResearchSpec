# Proposal

## Why

ResearchSpec needs to carry research results into patent disclosures and application drafts, and to use patent evidence in academic work. The patent-disclosure-skill upstream provides nine related business capabilities with document, figure, spreadsheet, knowledge-library and map tools that can share ResearchSpec's file contracts and graph authority.

## What Changes

- Pin the upstream at 5073d3d837a5d139ef2bc763c9dd46bb9605df84 and audit its complete source and resource inventory.
- Publish reviewed, vendor-derived fixed capability stages for all nine business capabilities, including disclosure protection-layout work, through the existing Procedure catalog.
- Add independent patent profiles and research-to-patent and patent-informed-paper composition profiles.
- Preserve reviewed tools and optional Obsidian/map integration with user-configured dependencies, services and bounded ordinary-file writes.
- Add deterministic conversion, source extraction, provenance, licenses and catalog-driven maintenance; extend asset authoring for binary bytes and per-resource licenses.

## Capabilities

### New Capabilities

- `patent-fixed-capabilities`: Patent business stages, material/output file indexes, document and evidence boundaries.
- `patent-workflow-profiles`: Independent patent graphs, round control and research/academic-paper composition.
- `patent-upstream-maintenance`: Pinned-source audit, deterministic generation, resource decisions and maintainable semantic review anchors.

### Modified Capabilities

- `research-task-usage`: Extend natural-task discovery to fixed patent work while retaining Navigate, standalone work and CLI-only graph authority.

## Impact

The change affects maintainer source/authoring, the bundled capability and profile registries, generated Procedures, documentation and package verification. Public command count and workspace/manifest schema versions remain unchanged. Runtime dependencies are user-managed and are not installed by conversion or ResearchSpec installation.
