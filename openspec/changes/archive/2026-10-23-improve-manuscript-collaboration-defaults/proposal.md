# Proposal

## Why

Real manuscript work can reach drafting without resolving delivery preferences, discussing the argument, or investigating evidence gaps. Ordinary revision packets also omit the existing browser review surface, so users must discover and request it themselves.

## What Changes

- Put material inspection, delivery clarification, discussion, evidence-gap research and direction alignment before substantive manuscript production or delegation.
- Reuse confirmed preferences and simplify bounded wording edits; make defaults proposals rather than silent decisions.
- Reconcile writing and formatting instructions with the confirmed source, delivery and citation requirements.
- Offer interactive review proactively for substantive revisions, prepare it only after selection, and expose the existing annotation-intake workspace through ordinary manuscript packets.
- Add observable collaboration scenarios and refresh affected generated packages and maintenance records.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `research-task-usage`: preparation and collaboration before substantive manuscript work, including delegation and continuity.
- `interactive-manuscript-review-workspace`: proactive review choice and ordinary manuscript packet availability using the existing v2 protocol.

## Impact

Changes affect Navigate's shared Skill/command renderer, ARSU preflight and authored procedure instructions, review-workspace hints, user documentation, dogfood scenarios and generated/audited content. No public command, schema, runtime dependency, formal Gate or browser feature is added. Existing source-capture, review-result validation and workflow mutation boundaries remain authoritative.
