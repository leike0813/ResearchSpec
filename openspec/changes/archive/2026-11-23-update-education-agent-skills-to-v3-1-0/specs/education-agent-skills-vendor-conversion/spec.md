## ADDED Requirements

### Requirement: Reviewed Education References Travel With Their Skill

The vendor projection SHALL retain reviewed static Markdown references at their relative paths, bound to the source inventory and complete-tree approval. The extension projection SHALL preserve the reviewed bytes and declare hash-bound knowledge references. A retained example SHALL have an explicit read condition in its procedure.

#### Scenario: A worked example is moved to a reference

- **WHEN** the canonical Skill links to a reviewed example in its references directory
- **THEN** the link resolves in both projections
- **AND** the reference is included in review, license attribution and change verification
