## Why

The seven published Materials-Science-Skills-For-LLM-derived Skills predate the
non-native vendor Skill standard. Their 22–25 line main files delegate ordinary
runtime behavior to short quickstarts and copied references, while the converter
has no explicit capability implementation map, complete-tree validator,
derivation record, or hash-bound approval for the generated trees.

## What Changes

- Replace the seven thin curated projections with complete ResearchSpec-authored
  Skill trees using the lowest sufficient thickness: one baseline Atomsk Skill
  and six selectively reference-backed scientific workflow Skills.
- Map every advertised capability to an Agent procedure or a concrete
  user-configured external tool, without adding bundled scripts, state, generic
  schemas, runners, provider clients, dependency installation, or hidden
  execution.
- Retain references only for substantial, conditionally needed domain detail;
  fold quickstarts, short safety rules, prerequisite lists, and ordinary failure
  handling into each complete `SKILL.md`.
- Preserve the immutable audit, seven fixed IDs, seven/five admission split,
  MIT licensing, existing source-neutral memberships, empty hard dependencies,
  fourteen external-resource decisions, and seven advisory/source-excluded
  relationships.
- Replace source-bound replacement-asset rendering with complete authored trees,
  explicit source-to-output derivation, non-native validation, and aggregate
  tree hashing.
- Bind production to the approved complete-tree hash and upgrade the isolated
  Materials converter, generated assets, documentation, tests, and release
  boundary to converter version 2.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `materials-science-skills-for-llm-vendor-conversion`: Require complete authored
  non-native Skill trees, explicit Agent/external-tool capability mappings,
  progressive-disclosure review, derivation metadata, complete-tree validation,
  and hash-bound converter version 2 output.
- `mvp-release-readiness`: Publish the approved complete Materials trees and
  their runtime-relevant references and provenance while excluding obsolete
  curation inputs and all maintainer-only review material.

## Impact

The change affects Materials converter policy, authored Skill sources, source
file dispositions, external-resource evidence, tree rendering and review state,
focused converter tests, generated Materials vendor assets, the assembled
registry, package verification, adapter and plugin documentation, and project
maintainer guidance. It adds no dependency, public command, domain, hard Skill
dependency, runtime LLM integration, automatic download, credential lookup,
scientific software execution, or workflow-state authority.
