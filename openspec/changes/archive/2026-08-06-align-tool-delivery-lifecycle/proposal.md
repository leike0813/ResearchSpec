# Align Agent Tool Delivery Lifecycle

Bring `init` and `update` in line with the current OpenSpec tool-delivery lifecycle while preserving the schema 1 file contract and ResearchSpec ownership boundaries.

The change updates the static tool catalog, introduces `skills`, `commands`, and `both` delivery modes, migrates Codex and Kimi project projections, protects shared/global Skill trees, and makes bootstrap reconciliation transactional and summary-oriented.
