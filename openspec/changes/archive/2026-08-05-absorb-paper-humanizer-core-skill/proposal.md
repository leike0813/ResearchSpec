# Absorb Paper Humanizer Core Skill

ResearchSpec shall absorb a pinned Paper Humanizer capability as a second Core Skill. It exposes independent read-only review and interactive full humanization routes, while keeping workflow lifecycle authority in ResearchSpec control files.

The change adds a pure Node runtime and generated Skill tree, extends route/profile/delivery contracts, and keeps the capability standalone rather than adding it to existing academic pipeline child graphs.
