# 对照表材料

从当前 Procedure 输入读取 `scene`、左列公开号或本地 `left.paths`、右列公开号、
产品或标准材料路径、允许补搜的范围。材料属于普通项目文件。

左列需要逐字权要、从权关系和说明书段落。已提供解读产出的特征行与段落切分时复用，
它们可在同一个 `claim_features` JSON 中，也可在明确绑定的辅助文件中。
缺少时只对本次选定专利做有界提取与语义补齐，
记录所用全文和证据位置。全文获取失败时请求 PDF，不补写不存在的证据。

补搜需要明确任务授权，并保留查询、命中和局限。新增辅助材料不代表任何图节点已经执行。
跨能力调用由 Navigate 发现并激活相应 Procedure。

将本次材料写成 `intake.json`，导出时以 `--into <本次输出目录>` 选择普通目录，
与 intake 保存在同一处。保留权要原文和实际路径，不用概括代替特征原文，不编造产品结构。
