把审阅集中到一个冻结的文档页

导入由 ResearchSpec Agent 生成的 review-workspace.v2 JSON。页面渲染这份冻结的审阅件，你在正文里划选文字，或对整段、整图、公式和引用标记整体批注；批注会实时出现在右侧。完成后导出 review-workspace-result.v2。

页面只在本浏览器中读取和保存草稿，不会改动手稿、SQLite 或 researchspec/，也不会重新渲染变化后的原文。生成审阅件时对应的原稿由 Agent 保留；交回结果后由 Agent 核对原稿是否变化，再决定如何应用批注。

正式 Gate、Decision 和节点状态仍由 Agent 重新读取当前 instructions 后，通过现有 CLI 确认。
