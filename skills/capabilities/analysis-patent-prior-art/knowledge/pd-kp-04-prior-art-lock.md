# 轻量查新与区别特征锁定 (Prior-art lock)

## 渠道分层

- A：国家知识产权局专利公布公告系统（epub.cnipa.gov.cn）。首选，按类型过滤，
  一词一页 + 摘要。
- B：Google 学术 / Google Patents。仅 A 不可用或结果不足时启用；专利类型过滤仍
  以 A 渠道为准。

## 摘要必用

命中条目含非空 `abstract` 时，检索说明与该专利的方案概括、应用场景、局限分析必须
先基于摘要理解。禁止凭标题或段号臆造；摘要与标题冲突时以摘要为准。无摘要时注明
「该条无摘要字段」，改用详情页或 Google Patents 补全后再写。正文不整段粘贴官方
摘要。

## D1 锁定

- D1 = 技术方案最接近的一篇，不是命中列表第一条，也不是公开日最新的一篇。命中
  顺序不是相关度排序，先按摘要打分再选。
- 须写一句选定理由。两篇几乎一样近时定一篇 D1、另一篇标 D2，不平均。
- 主表只对 D1，按技术维度逐行比对，给每条实质区别编号 F1、F2…（全案唯一、口径
  唯一）。编号单独成列，「本案怎么做」写满构造。D2 只作补行并标「组合风险」。
- 禁止把申请人、申请年份、是否授权、文献篇数当比对维度。

## 三态门禁

| 状态 | 何时 | 下一步 |
|------|------|--------|
| 过 | D1 同问题、手段重叠清楚，至少一条 Fk 落到 D1 的具体不足 | 进交底成文，预览点名 D1 与 Fk |
| 带疑点过 | 仍能点名出发点并写出实质区别，但证据不足或出发点不稳 | 进成文，必须写出不确定处 |
| 不过 | 写不出任何能落到具体对比文件不足的实质区别 | 仍成文，创造性论述降级 |

「不过」时禁止假 D1、禁止编造对比文件或链接、禁止空喊创新性强。检索说明如实写
「本次未钉住最接近现有技术」，Fk 对材料或本领域常规做法写并标明未经对比文件钉死。

## 检索说明写法

面向代理人或审查员：写公开数据库或渠道名称、主要检索词、分类号收口（IPC 或外观
LOC）。不得出现脚本名、Playwright、WebSearch、Agent、仓库名等内部流程元信息。
来源链接必须可访问且与著录项一致；照抄国知局 JSON 的 `link`，不得改域名，也不得
用 Google Patents 替换已有 `link`（补搜条目除外）。

## 产出

`prior_art_report`：检索说明、D1 / D2、Fk 表与特征一览、门禁状态与证据级别。定位
稿在内部或对话留档，不作为交底书表格的法定栏。
