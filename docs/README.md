# ResearchSpec 文档

文档按读者和维护周期组织：

- [用户文档](user/README.md)：从对话进入工作、运行、恢复和 CLI 参考；
- [开发者文档](developer/README.md)：架构、graph runtime、CLI、Adapter 与 Plugin 边界；
- [维护者文档](maintainer/README.md)：ARSU 吸收、vendor 标准、审计与发布。

`docs/` 只保存需要随产品长期维护的现行知识。可再生报告、发布证据、已完成评审、旧提案和历史
决策位于 [`artifacts/`](../artifacts/README.md)。能力作者输入位于 [`authoring/`](../authoring/)。

若文档之间存在冲突，[用户使用模型](user/usage-model.md)负责产品行为，OpenSpec main specs 负责
可验收要求，代码与 typed contracts 负责当前实现事实。
