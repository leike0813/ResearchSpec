# Phonopy quick start

1. Confirm the relaxed input structure, units, symmetry tolerance, and target
   observables.
2. Choose and justify a supercell matrix and displacement settings.
3. Generate a reviewed list of displaced structures and the force-calculation
   plan.
4. Obtain explicit confirmation before running DFT, ALM, remote, or scheduler
   work.
5. Validate force-file completeness and atom ordering before assembling force
   constants.
6. Check imaginary modes, sum rules, convergence, path conventions, and
   provenance before reporting physical conclusions.
