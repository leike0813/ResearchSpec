# Uni-Mol local workflows

## Representation extraction

Validate molecular identifiers and conformers, bind a compatible local model,
choose batching and device settings, and save embeddings with model and input
provenance.

## Property inference

Confirm that the model task, output units, and applicability domain match the
research question. Preserve raw predictions and attach uncertainty or limitation
notes where available.

## Execution boundary

Render the exact local command and expected output before execution. Obtain
explicit confirmation for GPU use or replacement of an existing file. Do not
retrieve models, data, or images and do not invoke remote endpoints.
