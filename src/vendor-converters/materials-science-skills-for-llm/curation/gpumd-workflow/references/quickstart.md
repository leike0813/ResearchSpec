# GPUMD quickstart

1. Confirm the scientific objective and whether the task is simulation, NEP
   training, or analysis.
2. Inventory the user-provided executable, GPU environment, structures,
   potential or dataset, and existing outputs.
3. Draft inputs in a new working directory and validate referenced paths.
4. Report the exact command, GPU request, estimated cost, and output effects.
5. Run only after explicit confirmation; never rebuild software or retry a long
   task automatically.
6. Check logs, conservation behavior, sampling adequacy, and output completeness
   before interpreting the result.
