## 0.1.0 - Release candidate

- Added the Schema 0.2 file-contract workspace and fifteen-command public CLI.
- Added routing, subflow instance, artifact Submit, Gate/transition, Decision, receipt, and dynamic revision-round control planes.
- Added universal ARSU workflow profiles covering 25 operational modes, two pipeline entries, and internal revision rounds.
- Consolidated the Agent surface to four ARSU and four Companion Skills across 31 registered tools, with wrappers for 28 command-capable tools.
- Added public-CLI acceptance journeys and requirement traceability for the canonical ARSU user model.
- Added clean npm packaging, installed-tarball verification, mixed-license attribution, and the Node 22/24 Linux/Windows release matrix.

The release remains unauthorized until the hosted CI and manual dogfood checklist are signed.
