# Glossary

**Boundary deliverable** — An ordinary project file outside `researchspec/`, referenced from a
handoff by role and safe path.

**Frozen graph** — The run-local copy of a profile that remains authoritative for that run.

**Decision** — A human-confirmed scope, claim, structure, branch, or failed-Gate override choice
stored in the owning node instance, or a project-change resolution stored in that change.

**Formal Gate** — A profile-declared academic checkpoint whose verdict requires human confirmation.

**Handoff** — A directly editable run document that records boundary input and output roles,
paths, purposes, sources, consumers, and limits.

**Project change** — A proposed high-impact update kept separate from stable specs until accepted,
explicitly applied, and validated.

**Graph profile** — A converter-owned graph template projected into the workspace.

**Stable specs** — The four owners for project intent, sources, claims, and manuscript structure.

**Run** — One frozen graph execution. Root runs are human-authorized; bound child runs inherit graph authorization.
