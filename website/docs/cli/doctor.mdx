# `researchspec doctor`

Diagnose runtime damage or apply one plan-bound deterministic repair

- **Group**: Recovery
- **Workspace**: `required`
- **Effect**: `conditional-write`
- **Related**: [`check`](./check), [`status`](./status)

| Option | Required | Description |
| --- | --- | --- |
| `--repair <finding-id>` | no | preview or apply a deterministically repairable finding |
| `--expected-plan-sha256 <hash>` | no | bind execution to the previewed Doctor repair plan |

:::info Runtime binding

Many options require a SHA-256 action-plan or action-basis binding
(`--expected-action-basis-sha256`, `--expected-plan-sha256`) when the
command is executed under a plan-bound workflow. Run
`researchspec instructions <selector> --json` for the exact required
semantic input and binding rules.

:::
