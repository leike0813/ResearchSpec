# `researchspec plugin list`

List bundled domain Skill plugins

- **Group**: Domain Skills
- **Workspace**: `optional`

- **Related**: [`plugin show`](./plugin-show), [`plugin install`](./plugin-install)

| Option | Required | Description |
| --- | --- | --- |
| `--installed` | no | show only workspace-selected plugins |
| `--summary` | no | emit compact discovery metadata |
