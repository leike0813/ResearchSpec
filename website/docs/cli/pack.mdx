# `researchspec pack`

Create a deterministic bounded schema 2 context bundle

- **Group**: Context
- **Workspace**: `required`
- **Effect**: `write`
- **Related**: [`handoff`](./handoff), [`check`](./check)

| Option | Required | Description |
| --- | --- | --- |
| `--output <zip>` | yes | output ZIP path |
| `--scope <scope>` | no | all, specs, profiles, runs, changes, run:<id>, or change:<id> |

#### Input shape

A required ZIP output and an optional bounded context scope.

| Field or option | Type | Required | Meaning |
| --- | --- | --- | --- |
| `--output` | `ZIP path` | yes | Destination archive path. |
| `--scope` | `all \| specs \| profiles \| runs \| changes \| run:<id> \| change:<id>` | no | Bundle scope; defaults to all. |
