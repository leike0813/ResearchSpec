# Software copyright upstream review

The selected tree is the upstream `v4.4.0` source declaration at commit
`6c9e6e72d8afce7aaccc9831ccd645a6ae2ccb16`. Upstream has no Git tag or
GitHub release for this version. The immutable commit and tree identify
the input. The catalog records the decision for each tracked file.

The selected snapshot and the identified Fokkyp v1.3 ancestor both carry the
same MIT grant. The ancestor's main branch changed to AGPLv3 in a later
revision outside this intake. Distribute the copied MIT notice with the
admitted code. The original example and assets stay outside the release.

The case entrypoint calls reviewed local rendering helpers only after checking
the specific files. The original repository scanner, confirmation runner and
upload guide are represented by the authored Procedure and case commands. The
browser guide relies on ordinary, visible controls and the applicant's session.
ResearchSpec's discovery, installation and static checks never run these tools.
