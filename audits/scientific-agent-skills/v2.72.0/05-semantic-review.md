## 流程权威与资源检查

- Raw 与扩展中的专业流程保持一致。扩展在独立的 ResearchSpec node contract 中声明唯一输入与输出、知识引用及六个 evidence 字段。
- 生成的扩展入口没有 next-node、next-phase、agent-team 或 proceed to next 指令。领域结论保持 advisory，既有 graph profile ID 和字节保持一致。
- 664 个知识文件与 raw Skill 逐字节一致。35 个退役的扩展资源已移除，其中 11 个是上游移除的 TimesFM 输出。TimesFM 文档保留模型权重的独立许可说明。
- 核对八个定向撰写的入口、45 项资源排除和安装后的工具路径。修正了 Modal 对退役凭据参考的依赖、PyLabRobot 示例对上游测试目录的依赖，以及 LaTeX 对本地预检脚本的说明。
- 许可按 Skill 分辨。扩展携带 raw Skill 的许可文本和署名。ToolUniverse 和 Materials 的包、profile 和原有成员保持原样，本次仅刷新了两份包含跨厂商共享成员的 registry 摘要。
