# Scientific Agent Skills v2.72.0 new analysis candidates

Each Skill declares MIT for the distributed Skill contents and has no dedicated upstream scan row. The decisions draw on static inspection at the pinned revision. External software, datasets and binary test fixtures remain outside distribution. The maintainer approved `clear-with-adaptation` and admission with the following constraints. [Decision record](artifacts/maintainer-decisions.json)

| Skill | Inventory and risk | Required adaptation and production domain |
| --- | --- | --- |
| `cellprofiler` | Four files include the author's analysis pipeline asset, a reference and one helper. A fixed argument-list invocation launches the user-selected local application. Scientific images and derived measurements stay in the authorized local environment. | Require a user-provisioned, trusted local application and a separate run directory. Keep image transfer and container provisioning outside the procedure. Domain `biomedical-engineering`. |
| `13c-metabolic-flux` | 16 files include three scripts, two references and ten assets. The local numerical workflow fits measured tracer data, and the bundled examples are synthetic. The adapted sample retains upstream MIT attribution. | Require local analysis and project-provisioned dependencies. Preserve the asset notice, report nonidentifiable parameters and keep the tests and external input datasets outside distribution. Domains `biochemistry-and-cell-biology` and `computational-modeling-and-simulation`. |
| `cantera` | Four files include a reference, an example asset and a local chemical kinetics helper. Runtime extensions and untrusted mechanisms can cross the execution boundary. Findings are about numerical sensitivity and method provenance. | Use a trusted, explicit local mechanism and provisioned runtime. Exclude untrusted code extensions from the recommended path and retain provenance and numerical limits. Domains `physical-chemistry` and `computational-modeling-and-simulation`. |
| `qiime2-amplicon` | Three files include a reference and a local wrapper that invokes the provisioned analysis tool through explicit arguments. Sample data and classifier provenance matter. The separate test fixture is outside the Skill tree. | Require authorized local inputs, a provisioned runtime, a fresh output location and traceable reference data. Keep externally hosted services and fixture installation outside the projection. Domain `microbiology`. |
| `relion` | Four files include two references and a local wrapper for the user-provisioned program. Reconstruction consumes substantial compute and diagnostics have limited scientific scope. | Confirm executable identity, local inputs and output location. Keep resource scheduling and external data transfer outside the capability. Domain `biochemistry-and-cell-biology`. |
| `tellurium` | Five files include one reference, a local simulation script and two demonstration assets. Model inputs belong to the user, and native runtime compatibility is platform dependent. | Accept trusted local models and use a new output directory. Keep external tooling, runtime provisioning and data retrieval with the user. Domains `biochemistry-and-cell-biology` and `computational-modeling-and-simulation`. |
